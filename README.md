# Trabalho de Desenvolvimento Web Básico - 1º Semestre 2024

Projeto desenvolvido para a disciplina de **Desenvolvimento Web Básico** no 1º semestre de 2024 durante o curso de Ciência da Computação na Universidade Positivo. O objetivo do projeto foi aplicar conceitos fundamentais de estruturação e estilização web.
---

## 🚀 Sobre o Projeto
O site consiste em uma Landing Page para uma sorveteria artesanal, apresentando o cardápio e informações de contato.

## 🛠️ Tecnologias Utilizadas
* **HTML:** Estruturação semântica do conteúdo.
* **CSS:** Estilização, layout e responsividade básica.
* **Imagens:** Otimizadas para carregamento web.

## 📁 Estrutura de Pastas
* `/img`: Imagens e ícones do site.
* `/css`: Arquivos de folha de estilo.
* `index.html`: Página principal do projeto.

---
> Este é um projeto para fins estritamente acadêmicos.
